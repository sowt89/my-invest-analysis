# 나만의 투자분석

미국 주식 40종목을 매일 자동으로 분석해, **이번 달에 살 종목 5개**를 알려주는 대시보드입니다.

**바로가기: https://sowt89.github.io/my-invest-analysis/**

설치할 것도, 로그인할 것도 없습니다. 링크를 열면 끝입니다.

---

## 1. 한 줄 요약

> 관심종목 40개 중 **최근 흐름이 가장 좋은 5종목**을 골라주고, 한 달에 한 번 그 목록이 바뀌면 갈아타는 방식입니다.

---

## 2. 어떻게 쓰나 — 한 달에 5분

**① 접속하면 맨 위에 이번 달 매수 종목 5개가 바로 보입니다.**

```
① MU    Micron Technology    $1,011.75   모멘텀 340.7
② INTC  Intel                  $103.49   모멘텀 165.4
③ AMD   AMD                    $506.00   모멘텀 116.3
④ PL    Planet Labs             $24.38   모멘텀 110.8
⑤ ARM   Arm Holdings           $271.43   모멘텀  64.7
```

**② 순위 변동은 월 평균 0.6종목입니다.** 대부분의 달은 목록이 그대로입니다.

**③ 화면 상단에 시장 국면(상승장·혼조·하락장)이 함께 표시됩니다.**

---

## 3. 화면 설명

앱은 하단 탭 3개로 되어 있습니다.

### 매수 종목 (첫 화면)
- **이번 달 매수 종목** — 모멘텀 상위 5종목
- **현재 시장 국면** — 상승장 · 혼조 · 하락장
- **모멘텀 순위** — 40종목 전체. 구간은 순위 묶음(`상위 5` · `6~15위` · `16위↓`)이며 매매 지시가 아님

### 종목 진단
실적 · 밸류 · 재무 3축 점수. **참고를 위한 측정**이며 백테스트로 검증되지 않았습니다.

### 종목 상세
선택한 종목의 모멘텀 순위, 1년 주가 차트, 밸류에이션(PER·PSR 등), 마진, 분기·연간 실적, 현금흐름, 애널리스트 전망을 한 화면에서 봅니다.

### 밸류 비교
40종목의 밸류에이션 지표를 표로 나란히 비교합니다. 마진이 기준 이상이면 초록, 미달이면 주황으로 표시됩니다.

---

## 4. 순위는 어떻게 매기나

두 가지 숫자를 반반씩 더해서 점수를 냅니다.

| 지표 | 뜻 |
|---|---|
| **모멘텀** | 최근 1개월을 뺀 1년 수익률. 꾸준히 오르고 있는가 |
| **200일선 이격도** | 현재가가 200일 평균가보다 몇 % 위에 있는가. 지금도 추세가 살아있는가 |

> **최근 1개월을 왜 빼나?** 지난달에 급등한 주식은 이달에 되돌림이 오는 경향이 있습니다. 그 노이즈를 제거하면 "꾸준히 오르는 종목"만 남습니다. 학계에서 30년 넘게 쓰이는 표준 방식입니다.

**예시 (MU):** 모멘텀 +603.5%, 200일선 이격도 +77.8% → 점수 (603.5 + 77.8) ÷ 2 = **340.7점**

## 5. 왜 이 방식인가 — 검증 결과

여러 방식을 과거 데이터로 시험한 뒤 남은 하나입니다.

### 26년 검증 (2000~2026, 닷컴버블·금융위기 포함, 15종목)

| 방식 | 최종 |
|---|---:|
| 15종목 전부 사서 보유 | 116배 |
| **모멘텀 상위 3종목** | **576배** |
| 무작위로 3종목 (대조군) | 65배 |

무작위 대조군이 오히려 보유보다 못하므로, **집중투자 효과가 아니라 종목 선택이 실제로 작동한 것**입니다.

### 4개 시대 모두 통과

| 시대 | 균등보유 대비 |
|---|---:|
| 2000-2007 닷컴버블+회복 | 1.78배 |
| 2008-2013 금융위기+회복 | 1.06배 |
| 2014-2019 강세장 | 1.37배 |
| 2020-2026 코로나~현재 | 2.10배 |

### 시도했다가 버린 것들

| 시도 | 결과 |
|---|---|
| 저평가(역발상) 점수로 매수 | 예측력이 오히려 **음수** |
| 점수 나빠지면 매도 | 그냥 보유보다 못함 |
| 200일선 이탈 시 매도 | 7개 지수 중 2개만 우위 |
| 신호 기다렸다 적립 | 그냥 매달 적립하는 게 나음 |
| 가중치 최적화 | 단순 반반이 더 나음 |
| 테마별 다른 규칙 | 우위 소멸 |

## 6. 꼭 알아야 할 한계

**① 최대 -50%까지 떨어진 적이 있습니다.**
26년 중 두 번은 자산이 반토막 났습니다. 견딜 수 있는 금액만 넣으세요.

**② 하락장에서는 "덜 떨어진 종목"을 고릅니다.**
상대 순위라서 전부 하락 중이어도 5개를 채웁니다. 2009년 2월에는 상위 5종목 중 4개가 마이너스였습니다. 상위권 점수가 대부분 마이너스면 시장 전체가 하락 국면이라는 신호이니, 비중을 줄이는 판단을 하셔도 됩니다.

**③ 워치리스트가 성과의 대부분을 결정합니다.**
부진한 종목만 모아둔 풀에서는 이 방식이 오히려 손해였습니다(0.23배). 좋은 종목을 골라 넣는 것이 여전히 가장 중요합니다.

**④ 세금이 수익을 크게 깎습니다.**
종목을 교체할 때마다 양도차익이 실현됩니다. 26년 시뮬레이션에서 세전 41억이 세후 9.4억이 됐습니다.

**⑤ 지수(QQQ 등)보다 낫다고 검증된 것은 아닙니다.**
검증된 것은 "같은 40종목 안에서 고르는 능력"입니다. 백테스트에 쓴 종목들이 이미 살아남아 성공한 회사들이라, 지수와의 비교는 출발선이 다릅니다.

**⑥ 급락은 못 피합니다.**
월 1회 점검이라, 하루 만에 -50% 나는 사건(파산·회계부정)은 피할 수 없습니다.

## 8. 직접 고쳐 쓰려면

### 관심종목 바꾸기
`scripts/fetch_data.py` 파일 맨 위 `WATCHLIST`에서 `("티커", "회사명", "테마")` 형식으로 추가·삭제합니다.

### 매수 종목 수 바꾸기
같은 파일에서 `r <= 5` 부분의 숫자를 바꿉니다. 참고로 검증 결과 종목이 적을수록 수익은 높지만 낙폭도 커집니다(top2: 최대 -58%, top5: -38%).

### 실시간 시세 키
[finnhub.io](https://finnhub.io)에서 무료 키를 발급받아 화면 우측 상단 ⚙ 버튼에 입력하면 개인 키로 동작합니다. 기본 키가 내장되어 있어 입력하지 않아도 됩니다.

### 파일 구성
```
index.html              화면 전체 (단일 파일)
scripts/fetch_data.py   데이터 수집 + 순위 계산
scripts/backtest.py     백테스트 (10년)
scripts/longbt.py       백테스트 (26년)
data.json               수집된 데이터
history.json            일별 지표 누적 기록 (최근 3년)
archive/history-YYYY.json  3년이 지난 기록 (연도별 보관)
.github/workflows/      자동 갱신 설정
```

## 9. 면책

이 도구는 개인이 과거 데이터를 분석해 만든 참고용 대시보드입니다. **투자 권유가 아니며, 미래 수익을 보장하지 않습니다.** 과거에 통했던 방식이 앞으로도 통한다는 보장은 없습니다. 투자 판단과 그 결과는 전적으로 본인 책임입니다.
